Why I built this

I built slm-lab for three reasons:

  • The learning tools I wish I'd had. When I started, explanations were either hand-wavy analogies or dense papers. This is the middle I wanted: real, runnable code with every step narrated in plain English.
  • To make AI's concepts accessible to non-specialists. You shouldn't need to be an ML engineer to build intuition for how these models actually work — and what they can and can't do. No prior Python required to read along.
  • To leave reusable patterns, not just a demo. Each chapter is a template you can lift: pre-training a model from scratch (Part 1), and the post-training playbook (Part 2) — distilling a big model's judgement into a small, cheap one, and turning messy, unstructured data into clean structured summaries.
