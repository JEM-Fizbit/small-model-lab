# Rare-class diagnostic — results

**What this is.** A held-out measurement set of **402 trials**, ~45 per rare modality, built because
the frozen 150-trial test set cannot resolve rare-class performance: it holds 5 ADCs, 3 oncolytic
viruses and 2 bispecifics, so one trial is worth 20–50 recall points. Rationale, construction and
limitations: **ADR-0020**. Never trained on; verified 0/402 overlap with the raw pull, every gold
split, the Phase-4 augment and the v1 archive.

**This is not the headline.** The published score remains the frozen 150-trial set
([`PHASE6_RESULTS.md`](PHASE6_RESULTS.md)), which is representative and comparable over time. This
set is deliberately *unrepresentative* — it over-samples the tail so the tail can be seen at all.
Quote it for rare-class questions only.

Generated by:

```bash
uv run python track-b-trialscout/eval/infer_and_score.py \
    --model mlx-community/Qwen3-4B-Instruct-2507-4bit \
    --adapter track-b-trialscout/train/adapters/qwen_v2s_aug \
    --label qwen_v2s_aug_diag --gold rare_diagnostic --batch-size 4 --memory-limit-gb 8
```

## The finding

**Rare-class augmentation worked. The frozen test set could not see it.** Three classes it reported
as *exactly unchanged* — ADC, oncolytic virus, bispecific — show gains of +0.14, +0.12 and +0.07 once
there are 42–45 trials instead of 2–5.

**It was also reporting wrong levels, not just wrong deltas.** ADC 0.40 vs **0.77** actual;
bispecific 0.00 vs **0.73**. Those were 2-of-5 and 0-of-2 samples. Any statement about this model's
rare-class capability sourced from the frozen set is unreliable, including ones previously made in
ADR-0017 and on the walk-through, both since corrected.

**`other protein or peptide therapeutic` is the exception that confirms the rule.** It has ample
training support (127 rows) and ample diagnostic support (n=43), and the delta is **+0.00**, stuck at
0.56. Not a rarity problem — a badly-drawn category, and a candidate for splitting in schema v3.

**Gene therapy remains unmeasurable** (n=1). The search terms returned trials the teacher classified
as cell therapy or oncolytic virus, which is defensible — oncology gene therapy largely *is* those.

## Before quoting these numbers

The diagnostic shares its sampling method with the augment training data: both come from the same
ClinicalTrials.gov term searches. The NCT ids are disjoint and verified, but the *distribution* is
not independent, which mildly favours the augmented model. The gains are real; on a natural sample
they would likely be smaller. The frontier arm has **not** been run on this set, so the remaining
student-vs-frontier gap on rare classes is unquantified.
